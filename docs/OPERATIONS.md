# 自动设计运行与恢复

根目录 start.ps1 一条命令启动理解8101、规划8102、交付8100。网页 http://127.0.0.1:8100 是唯一入口；stop.ps1只停止本项目启动的进程树，端口冲突不杀未知进程。

1. 上传一份DXF并点击开始。自动读取内部商品/物料，解析明确空间事实。
2. 完整输入直接进入规划、几何检查和交付，无人工确认。
3. 少量源scope端点缺口显示原图端点候选，只需选择并提交。未知图层显示既有源图元分类选项；真正缺失的范围/入口才显示必要绘图工具。
4. 补充后系统自动运行到底，无二维阶段审批、返回聊天或再次点击继续要求。
5. 三维显示地面、孔洞、墙、禁放区、入口、连续排及全部模块层板。左键旋转、滚轮缩放、右键平移，按钮俯视/复位，点击货架查看规格。
6. 设计级清单包含物料编号、长深、默认层数、数量、总层数；下载布局JSON和XLSX。高度显示假设不进入采购真值。

确认缓存由CAD字节SHA、当前完整业务与物料、规则和解析政策版本绑定；每次重传重新读取源和固定约束、验证签名/几何后才能复用。无需重复确认相同有效事实。缓存损坏不自动放行；配置变化不可复用旧包。

runtime/understanding_v2保存CAD准备证据及确认缓存，runtime/workbench/jobs.sqlite3保存任务，runtime/confirmation.key是本地完整性密钥，不入Git。待补充或已完成任务可通过?job=ID恢复；未提交草稿不持久化。重启将中断任务明确标记失败，重传会复用已保存的有效补充；不让用户重新做技术审批。

S1只加载分类允许的内部业务文件。S2只消费标准JSON，不读CAD/参考。S3只通过本地HTTP协调，参考指标和图仅结果后按需读取，不作为生成输入。

普通服务或算法故障显示具体失败；输入事实错误保留待补充状态并显示原因。不得把无效范围“确认”成有效，也不得自动补墙闭合粗框。原件保护复验：.venv/Scripts/python.exe -B -m scripts.audit_sources。

所有依赖、浏览器、缓存、TEMP、数据库和产物在项目内。独立服务命令见各服务README；完整操作负担和真实边界限制见ACCEPTANCE.md。
