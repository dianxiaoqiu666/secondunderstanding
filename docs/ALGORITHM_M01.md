# M01 标准矩形连续货架排

状态：阶段 A 技术验收通过；尚未进入障碍、真实空间或产品验收。不能宣布项目 COMPLETE。

主要缺陷：旧版以单个货架为规划单位，每两个模块间加入过道，产生孤立、稀疏的货架。

最小假设：先按整个连续排分配空间，再用精确长度组合填充排；同排模块首尾相接，过道只在不同排与排端保留。

实现边界：`services/planning/runs.py` 只接收标准 PlanRequest；不打开文件、不解析 CAD、不读取参考画像。CONFIRMED 或 SYNTHETIC_TEST 必须绑定 source SHA256 和 geometry digest，未确认、未决或无效几何直接拒绝。HTTP 身份签名和拒绝 synthetic 由接口层负责。M01 明确拒绝孔洞、障碍、入口和凹形范围，等待下一阶段。

算法使用 Shapely/GEOS 做几何构造、相交、距离和并集。0°/90°分别按模板深度分组生成整排，网格由输入局部 bounds 定义。默认排间1200mm、排端1200mm、边墙100mm，均来自 PlanningRules。排尾未使用长度在两端等分；横向余量在两侧等分。每排至少两个模块，不生成单体。

模块组合是针对一维物料长度的确定性 DP：按模板真实小数精度和最大公约数建整数长度状态；优先最小排尾，其次最少模块数量，最后 material_id 字典序。模块计数饱和状态保留“两个短模块”与“一个长模块”的区别。资源超过200000状态或10000模块时明确拒绝。6300mm 得到完整4模块混长组合，新增1250模板使2500mm排尾由100降为0，无需新增算法分支。

候选先独立验证安全，再按平均每排模块数、平均连续排长、有效总长度、排尾、模块数、方向和深度的稳定顺序比较。没有层板面积、商品容量或模板层数评分。商品精确上架维持 UNAVAILABLE-DUE-TO-MISSING-PHYSICAL-DATA。

输出 ShelfRun 含完整模块；平铺 shelves 与 runs.modules 严格一致。BOM 从最终模块汇总，含 total_level_count。独立校验重新构造每个矩形，验证中心/规格/方向、模块连续、整排并集、边墙退让、排端、排间过道和BOM。
