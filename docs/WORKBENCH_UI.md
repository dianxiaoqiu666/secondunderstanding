# 自动交付网页（M05）

workbench.html/css/js为唯一入口，viewer-v2.js使用项目内Three.js和OrbitControls展示最终LayoutV2。旧M04强制审核与二维停机说明在_archive/M04_MANUAL_WORKBENCH/docs/WORKBENCH_UI.md。

正常流程：上传DXF、点击开始，自动处理到complete，展示3D/2D/品类/设计清单并下载JSON/XLSX。完整输入editor-panel隐藏，没有确认按钮或五项勾选。新上传使旧异步响应失效，防止结果串任务。

仅awaiting_confirmation显示必要问题。原图源句柄可高亮，短缺口显示两个真实源端点和候选连线；用户选一个选项并点击提交就继续。局部选项场景不展示重画工具或五项勾选。真正缺失的几何才显示对应绘图工具和必要字段；源固定墙、显式孔洞、HATCH和入口保留。缺事实导致的错误在同页明确显示，不会吞掉补充失败原因。

未提交的绘图草稿不保存；已有效提交的事实由S1按内容验证复用，用户无需回聊天。旧任务恢复不自动虚构确认；当前任务从ready到complete全自动。

三维展示地面孔洞、墙、禁放区、入口、连续排、每模块和默认层板。左键旋转、滚轮缩放、右键平移，俯视/复位，真实raycaster点选规格。货架高1800、墙高2600/厚100mm仅显示假设，页面与XLSX说明。__L3_VIEWER__暴露实际场景和相机观察供验收，不用来注入已确认状态。

参考表/图在生成后读取，使用独立坐标视图；跨店面积和规则不同不能硬判数量或密度。诊断不要求门店老板逐阶段审批，也不当生产数据使用。

真实操作负担证据见tests/autonomous_v3与outputs/acceptance_m05。完整/局部/复用是明确测试图；真实原CAD缺事实样例单独记录未完成和操作总数未知。
