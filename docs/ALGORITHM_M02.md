# M02 障碍环境中的连续货架排

本轮唯一目标：将 M01 整排模型扩展到柱、内墙、孔洞、入口和凹形范围，保持连续模块和明确的基础过道；不回退为独立货架扫描。

开发按 column → wall → hole → entrance → concave 逐组进行，每组单独运行实测并记录后才开放下一组。没有使用成熟参考坐标、数量、句柄或原 CAD。输入仍仅为标准 PlanRequest。

## 几何方法

候选排的方向与横向排列沿用 M01 的局部 bounds 网格；AABB 只决定枚举范围，绝不成为实际规划域。先用 Shapely/GEOS 对真实范围做退让，扣除墙、孔洞、禁放区和入口，再用完整排深度的条带与真实可用域做差集。把差集中每一块禁止几何投影到排轴，切出能容纳完整矩形排的连续区间。斜墙采用保守投影，可能多留空地但不让模块穿墙。

每个连续区间两端留足 end_aisle_mm 后运行原精确 DP，少于 min_modules_per_run 的区间拒绝；每个保留排至少两个首尾连接的模块。没有独立架 fallback。模板深度仍统一分候选，允许混长度，排序目标沿用 M01，算法版本更新为 whole_run_dp_v2_m02。

墙的预退让采用 max(wall_clearance_mm, boundary_clearance_mm)，再补 max(0,end_aisle_mm-boundary_clearance_mm)，因此在非默认 wall50/boundary300 时不会出现排端只剩950mm的漏洞。这可能比单独墙规则更保守。入口被视为已经确认的净空区域，货架不进入或接触；孔洞同样禁止接触。

独立验证不相信几何申报：重新构造模块和整排并集、检查真实范围/孔洞/墙/禁放/入口、测量所有不同排净距，并构造两端实际通道矩形，验证通道不越界、不穿洞、墙或禁放区，不被其他货架占用。继续重新计算 M01b 的质量指标和邻排关系。

通行结论仅覆盖局部排间净距与排端通道。结果明确写明不证明全店连通、入口到每个货架可达、无障碍或消防合规。用户确认的入口区域仍为空，但没有凭此伪称全店可达性。
