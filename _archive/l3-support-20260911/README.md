# 平面与货架 L3

上传满足要求的 CAD，系统自动理解空间、组合连续货架排、分配品类、检查安全，并显示交互 3D、设计级货架清单和下载。完整输入不要求重新绘图或逐项审核；少量缺口只补必要局部事实，提交后自动继续，同源有效补充可复用。

## 启动与使用

在本项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

打开 http://127.0.0.1:8100，选择任务和一份 DXF，点击“读取图纸”。三个服务与依赖均在本机，运行无需互联网或云端 AI。

**当前 M09 算法入口：**打开 [明确空间 · 算法验证](http://127.0.0.1:8100/algorithm?scenario=column)，选择固定测试场景，点击“生成并比较”。不需要 CAD 或范围确认，直接显示同尺度二维前后方案、连续排指标和物料数量。场景明确标注为测试输入，真实门店状态保持不变。参数、计量口径与接口见 [M09 说明](docs/PLANNING_M09.md)，实际结果见 [M09 复验记录](outputs/planning_m09/RESULT.md)。

- **查看已有设计**：展示这次上传图中的可靠结构和已有货架位置，不重新摆放。允许主动上传历史参考 CAD，并保留其原分类。无可靠范围时不造地面；图例、未知对象不计入已有货架清单，真实高度和层数未知时明确说明。
- **生成新货架规划**：使用有效标准空间和内部业务配置自动生成。参考文件仍不能作为新规划的生产输入。

- 有效完整 CAD：等待自动交付，无额外操作。
- 局部缺口：点击问题摘要或“定位图上位置”，依旁边的操作方法选已有候选、原线或精确源端点，先预览，再“应用并检查”。不必重新描整圈；补充范围线不会自动成为墙。
- 源线含义：按实体处理，Defpoints 和图层 0 都不能直接证明它是辅助线或墙。已验证的局部源事实保存并按文件及配置复用；撤销不会删除其他已完成事实。
- 实际范围或入口确实缺失：只补对应事实；程序不会猜外墙、自动批准粗框或复制成熟图坐标。
- 再次上传相同字节且相关资料未变：自动复用仍有效的签名补充。缓存损坏或资料变化会重新验证。
- 结果页可旋转、缩放、平移、重置视角，点击货架查看规格，下载布局 JSON 和 XLSX。二维与参考对照为生成后的诊断，不要求阶段审批或返回聊天。

停止服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\stop.ps1
```

## 验收与边界

[M08 当前复验与剩余事实](outputs/scope_m08/RESULT.md) 和 [失败不变量](LEGACY_FAILURES.md) 记录整店资格、开放外围工作、微距端点操作与撤销复用。局部柱体不可作为整店，外围未闭合时可保存工作进度。原真实文件仍没有已确定的整店范围；165 已作为墙使用不代表范围已齐备，不能将合成流程通过称为真实门店已完成。[M07](docs/M07_DELIVERY.md)、[M06](docs/M06_DELIVERY.md) 等旧阶段报告保留为历史资料。

先停止已有服务再运行全部测试（会实际启动三个服务及浏览器）：

```powershell
.venv\Scripts\python.exe -B -m pytest -q --basetemp=.tmp/pytest-manual
.venv\Scripts\python.exe -B -m scripts.audit_sources
```

输入契约见 [自动输入与必要补充](docs/AUTOMATIC_INPUT.md)，接口见 [API](docs/API_CONTRACT.md)，算法见 [连续排](docs/ALGORITHM_M01.md)、[障碍](docs/ALGORITHM_M02.md)、[商品分配](docs/PRODUCT_ALGORITHM.md)，迭代见 [ITERATION_LOG](ITERATION_LOG.md)。

只支持明确单位为毫米的安全二维 DXF 子集。当前方向0/90度，过道为基础局部几何规则，不代表全店可达或消防认证。真实SKU缺包装宽深高，不伪造精确上架/容量；物料无完整高度、零件、价格和库存。三维高度仅显示假设，XLSX是设计级模块清单。
